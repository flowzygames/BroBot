GOOD QUESTIONS

A few things
worth knowing.

Is this an official Minecraft product?

No. BroBot is an independent project. It is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft.

Does it need an AI subscription?

Direct commands and the experimental offline starter do not need an API key. The optional language planner uses paid OpenAI API calls, billed separately from ChatGPT subscriptions. There is no integrated offline language model.

Can it beat Minecraft on its own?

That has not been demonstrated. The current starter objective is much narrower: gather materials, make a stone pickaxe and furnace, and return home. Difficult terrain and survival hazards can still stop it.

What does Windows support mean?

The project includes Windows setup and automated Windows checks have passed for earlier published code. Actual rendered Minecraft gameplay on Windows is still unverified in this development work. Check the current branch’s CI and full play guide.
