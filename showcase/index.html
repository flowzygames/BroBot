QUICK START
git clone https://github.com/flowzygames/BroBot.git
cd BroBot
git checkout feat/starter-recovery-and-readme
npm ci
npm run setup
npm run play

Review the Minecraft EULA during setup. Leave the API key blank for direct commands. Keep the default local-only network settings.
