THE ALPHA 1 CHECKLIST

Useful first.
Reliable next.

✓ Direct commands and bounded action execution

✓ Experimental offline starter controller

✓ Named benchmarks with retained failures

✓ One full starter development success after recovery fixes

○ Repeat success across more worlds and terrain

○ Broader live interruption, death and reconnect tests

○ Actual Windows and Bedrock client playthrough

○ Review and merge the draft implementation

○ Separately authorized live language planner evaluation
