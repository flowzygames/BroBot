FROM INSTALL TO YOUR FIRST COMMAND

Six steps.
One teammate.

  1. Get the right build

    Download branch feat/starter-recovery-and-readme. The new starter features are in draft PR 7 and may not be on the default branch.

  2. Run the launcher

    Install Node.js 22.9 or newer. Windows: open Start-BroBot.cmd. macOS/Linux: run sh start-brobot.sh. It installs dependencies and opens setup. An API key is optional.

  3. Start the local world

    The launcher starts the server after setup. Review the Minecraft EULA and wait for startup. If you used the manual Git instructions instead, run npm run play once. Java 21 is downloaded if needed.

  4. Open the dashboard

    Visit http://127.0.0.1:3000 on that same computer. Set your owner name to the connected player name.

  5. Join Minecraft

    Java 1.21.8 uses 127.0.0.1:25565. Supported Bedrock clients use 127.0.0.1 on port 19132 through Geyser.

  6. Try a small task

    Start with status, inventory and follow me. In Minecraft chat, use !bro follow me. Use stop to interrupt.

Keep it local.

The default setup disables server authentication and binds listeners to your computer. Do not expose it to the internet. You still need a licensed Minecraft client. Stopping the bot does not pause the world.

GOOD QUESTIONS

A few things
worth knowing.

Is this an official Minecraft product?

No. BroBot is an independent project. It is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft.

Does it need an AI subscription?

Direct commands and the experimental offline starter do not need an API key. The optional language planner uses paid OpenAI API calls, billed separately from ChatGPT subscriptions. There is no integrated offline language model.

Can it beat Minecraft on its own?

That has not been demonstrated. The current starter objective is much narrower: gather materials, make a stone pickaxe and furnace, and return home. Difficult terrain and survival hazards can still stop it.

The starter stopped on a treetop or near a steep drop. Now what?

Some terrain has no verified walking route back. Don’t keep restarting the same blocked task. Use stop, guide BroBot with follow me to open, solid ground, stop following, then start a new survive starter job there. A new job uses that location as its starting point; survive resume keeps the old one. The benchmark worlds are never repositioned this way.

How do I check a startup problem?

Open a terminal in the extracted BroBot folder and run npm run doctor. Keep the full error message. If a port is already in use, check for an existing BroBot window before starting another. Don’t delete your world or expose local ports to the internet to fix setup.

What does Windows support mean?

The project includes Windows setup and automated Windows checks have passed for earlier published code. Actual rendered Minecraft gameplay on Windows is still unverified in this development work. Check the current branch’s CI and full play guide.
